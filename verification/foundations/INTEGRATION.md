# Foundation adapter integration

Entry: `foundations.py STAGE --output NEW_DIRECTORY [--timeout SECONDS]`, using the caller's current Python. Run with `python -I -B`. The programmatic API is `foundations.run(stage, output, timeout=54000)`. `tasks.json` declares seven full numerical stages and two explicitly partial source/smoke operations.

Full stages: `n2-scalars`, `n2-primary`, `n2-independent`, `n3-scalars`, `n3-identities`, `n3-full`, `root4-two-pass`. The root4 full stage requires Linux with the bundled established native guard. G3 full requires `g++` and Boost headers on PATH. All original G2/G3 programs and coefficient witnesses, and the full original99-file ROOT4 source package, are included. No private key, HMAC or old runtime/compiler-profile identifier is needed. No original mathematical program was edited.

Actual checks performed during implementation:

* Original G2 `verify_reductions`: EXIT0.
* Whole original G2 cell000: EXIT0,210 tensor nodes and1 moment box; repeated through the final adapter after its runtime/timeout changes.
* ROOT4 source preparation: EXIT0, sealed Linux epoch `63f409...`,73 mathematical ASTs/125 pin edges, exact native produce/replay arguments. No numerical ROOT4 computation was invoked.

No full70/111/ROOT4 run was launched. Those full tasks are implemented and must actually be requested/run before being marked complete. `root4-two-pass` invokes the existing unchanged controller, retains its original native limits and actual guarded source/capture validators, then explicitly rejects a complete UNKNOWN result. It supplies the conditional physical-class numerical result only, never an all-law C4 theorem by itself.

`RUNTIME-BEFORE.json`/`RUNTIME-AFTER.json` record the newly observed interpreter and (for G3 full) compiler, adapter/validator and package-manifest identities. They are compared, not authenticated using a historical authority. The adapter does not claim a hermetic compiler/system-library closure. New native logs, complete per-cell summaries, fresh C++ binary/process traces and actual ROOT4 reports remain in the output directory.

Publish `PUBLICATION.json` and exactly its listed files. Omit `demo-*`: those are task-local test outputs, not public source dependencies. The two source ZIPs total710099 bytes; they include original licenses. The optional historical `root4-export.zip` is unnecessary for fresh full production and is intentionally not copied, avoiding operational/private payloads. The public source package does not rely on stopped VMs.

Every result retains `full_pass=false` and `all_law_theorem_verified=false`. This is an executable foundation adapter, not an assertion that the unfinished overall public replay has passed.
